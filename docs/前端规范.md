# 37AC 前端（PHP Web 应用）规范

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 后端语言 | PHP 7+ | 原生 MVC 架构 |
| 路由 | 自定义 Router 类 | `router.php` — 支持 GET/POST，参数绑定 |
| CSS 框架 | Pico CSS 2 | 轻量级语义化 CSS 框架 |
| JavaScript | 原生 JS + jQuery 1.10.2 | auth.js 封装 JWT 认证 |
| 图片裁剪 | Cropper.js 1.6.1 | 浏览器端裁剪 |
| 去背景 | Canvas 原生 + @imgly/background-removal | 可选快速/AI 模式 |

## 视图渲染流程

```
入口文件 (public/index.php)
  → 加载 .env 环境变量
  → 定义 API_BASE_URL
  → 注册路由 (Router)
  → 路由分发
      → 控制器方法
          → $this->view('home/about', $data)
              → layout.php (Header + Meta + Nav)
                  → home/about.php (主体内容)
                      → footer.php (Footer + Scripts)
```

## 控制器规范

### 基类 Controller (`controllers/controller.php`)

```php
// 渲染视图
$this->view('home/index', ['title' => '首页', ...]);

// 返回 JSON
$this->json(['success' => true, 'data' => [...]], 200);

// 重定向
$this->redirect('/dashboard');

// 获取 POST/GET 参数
$this->post('email');
$this->get('page', 1);
```

### 视图数据约定

所有视图必须传递以下 SEO 数据：

```php
$data = [
    'title'       => '页面标题',              // 必填
    'description' => '页面描述',              // 必填
    'keywords'    => '关键词1,关键词2',        // 选填（默认继承）
    'canonical_url' => '/about',              // 必填
    'og_image'    => 'https://...',           // 选填
    'robots'      => 'index,follow',          // 选填
];
```

## 视图规范

### 布局 (`layout.php`)

- `layout.php` 负责：DOCTYPE、HTML head（SEO meta、OG/Twitter card、JSON-LD）、加载遮罩层、导航栏、全局 Notify/Modal
- 所有视图在 `layout.php` 之后渲染，最后 `footer.php` 收尾
- 加载遮罩层 ID 为 `_loading-overlay`，内容容器 ID 为 `_content`

### 视图文件结构

```php
<?php
require_once ROOT_PATH . '/views/layout.php';
?>

<div class="container" id="_content">
    <!-- 页面内容 -->
</div>

<?php
require_once ROOT_PATH . '/views/footer.php';
?>
```

## CSS 规范

### 框架

- 使用 **Pico CSS 2**（`pico.min.css`），语义化 HTML 自动获得样式
- 不引用 Bootstrap，移除 `bootstrap.min.css`、`bootstrap.js` 等旧依赖

### 命名约定

- 全局自定义样式使用 `_` 前缀（如 `_loading-overlay`、`_content`）
- 仪表盘组件使用 `dashboard-` 前缀（如 `dashboard-subnav`、`dashboard-nav-desktop`）
- 模态框使用 `modal-` 前缀（如 `modal-notification`）

### 间距

- 使用 Pico CSS 内置间距，不写行内 `style` 属性
- 如需自定义，在 `<style>` 块中统一声明

## JavaScript 规范

### 全局 API

```javascript
// 通知模态框
Notify.success('操作成功');
Notify.error('操作失败');
Notify.info('提示信息');

// 通用弹窗
Modal.show('标题', '内容 HTML', [
    { text: '确定', class: 'primary', click: () => { ... } },
    { text: '取消', click: () => {} }
]);
Modal.close();

// 后端 API 地址
window.API_BASE_URL;  // 如 'http://127.0.0.1:13138'
```

### 认证模块 (`auth.js`)

```javascript
// 发送 API 请求（自动携带 JWT 令牌）
Auth.fetch('/api/endpoint', { method: 'POST', body: ... });

// 登录
Auth.login(username, password);

// 登出
Auth.logout();

// 注册
Auth.register(username, email, password);
```

## 路由规范

### 路径定义

所有路由在 `public/index.php` 中注册：

```php
$router->get('/about', 'home_controller@about');
$router->post('/contact', 'home_controller@send_message');
```

### 认证保护

需要登录的路由使用 `require_auth()` 中间件：

```php
$router->get('/dashboard', function () {
    require_auth();
    $controller = new dashboard_controller();
    $controller->index();
});
```

## SEO 规范

- 每个页面通过 `layout.php` 自动生成：title、description、keywords、OG/Twitter card、JSON-LD structured data
- 所有页面设置 `canonical_url` 防止重复内容
- 站内链接使用相对路径，外链使用 `rel="nofollow"`

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `API_BASE_URL` | Flask 后端 API 地址 | `http://127.0.0.1:13138` |

存储在 `www/.env` 文件中，由 `public/index.php` 加载。
