# 37AC 前端（PHP Web 应用）规范

> 2026-08 重构后版本。设计系统代号「樱花拿铁」：明亮轻快 + 萌系，唯一强调色樱花粉。

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 后端语言 | PHP 7+ | 原生 MVC（VC 模式，无 Model 层） |
| 路由 | 自定义 Router 类 | `router.php` — 支持 GET/POST，参数绑定 |
| CSS | 自研 AC 设计系统 | `ac-tokens.css`（变量）+ `ac-components.css`（组件） |
| 字体 | Nunito + JetBrains Mono | 可变字重，woff2 自托管于 `static/fonts/` |
| 图标 | Phosphor Icons | web font，自托管于 `static/css/vendor/phosphor/` |
| JavaScript | 原生 ES Module | `app.js` 全局模块 + `auth.js` JWT 认证 |
| 图片裁剪 | Cropper.js 1.6.2 | 自托管于 `static/scripts/vendor/` |
| 去背景 | @imgly/background-removal 1.7.0 | ESM 自托管，WASM 模型走自托管 publicPath |

**重要约定：全站 PHP 页面零外部 CDN 引用。** 任何新前端依赖必须下载到 `static/scripts/vendor/` 或 `static/css/vendor/` 后引用，避免 CDN 不可达导致整页功能失效。

## 设计系统约定

### 色彩

- 唯一强调色：樱花粉，全站锁定（`--ac-pink-*` 色阶，按钮/链接用 `--ac-pink-600`，白字对比度 5:1 过 WCAG AA）
- 点缀色薄荷青 `--ac-mint` 仅用于小标签/状态点缀
- 语义色：success / warning / danger / info 各配浅色底
- 禁纯黑文字（主文字 `--ac-ink-900: #322931` 暖灰黑）、禁纯黑投影

### 形状（Shape Lock，全站唯一规则）

- 按钮、徽章、chip：`--ac-radius-pill`（999px 全圆角）
- 输入框、下拉：`--ac-radius-input`（12px）
- 卡片：`--ac-radius-card`（16px）
- 模态框：`--ac-radius-modal`（20px）

### 动效

- 交互反馈统一回弹曲线 `cubic-bezier(.34,1.56,.64,1)`，150-250ms
- 营销区块进入视口渐入：给元素加 `.reveal` 类，`app.js` 的 IntersectionObserver 自动处理
- 全部动效已做 `prefers-reduced-motion` 降级

### z-index 层级表（全站仅使用这些值）

`--ac-z-nav: 100` / `--ac-z-dropdown: 200` / `--ac-z-modal: 500` / `--ac-z-toast: 600` / `--ac-z-loading: 900`

## 视图渲染流程

```
入口文件 (public/index.php)
  → 加载 .env（API_BASE_URL / UPLOAD_API_KEY / APP_DEBUG）
  → 注册路由 → 路由分发
      → 控制器方法
          → $this->view('home/about', $data)
              → layout.php（head + 导航 + <main>）
                  → 页面视图（主体内容）
                      → footer.php（页脚 + </body></html>）
```

注意：`layout.php` 与 `footer.php` 各负责一半的文档闭合，**不要在视图里输出 `</body>` / `</html>`**。

### 视图数据约定

```php
$data = [
    'title'         => '页面标题',            // 必填
    'description'   => '页面描述',            // 必填
    'keywords'      => '关键词1,关键词2',      // 选填
    'canonical_url' => '/about',              // 必填（不含敏感参数）
    'og_image'      => 'https://...',         // 选填
    'robots'        => 'index,follow',        // 选填
];
```

页面级 CSS 文件通过 `$extra_css` 数组在引用 layout 前声明：

```php
<?php
$extra_css = ['/static/css/vendor/cropper.min.css'];
require_once ROOT_PATH . '/views/layout.php';
?>
```

## JavaScript 规范

### 全局 API（app.js）

```javascript
// HTML 转义：所有 API 返回的动态文本插入 DOM 前必须转义
escapeHtml(userInput);

// Toast 通知（右上角堆叠，按纯文本渲染，天然防 XSS）
Notify.success('操作成功');
Notify.error('操作失败');
Notify.info('提示信息');

// 确认弹窗（title 纯文本；bodyHtml 中的动态数据由调用方负责转义）
Modal.show('标题', '内容 HTML', [
    { text: '确定', class: 'btn btn-primary btn-sm', click: () => { ... } },
    { text: '取消', class: 'btn btn-ghost btn-sm', click: () => Modal.close() }
]);
Modal.close();

// 后端 API 地址
window.API_BASE_URL;  // 如 'http://127.0.0.1:13138'
```

### 认证模块（auth.js）

`window.Auth` 已显式挂载（顶层 `const` 不会自动挂 window，改动时注意保留 `window.Auth = Auth`）。

```javascript
Auth.fetch(url, { method: 'POST', body: ... });  // 自动携带 JWT + 过期自动刷新
Auth.get(url); Auth.post(url, data); Auth.put(url, data); Auth.del(url);
Auth.getUser();   // { username, role, user_id } 或 null
Auth.getToken();
Auth.logout();
```

## 仪表盘 SPA 结构

- `dashboard/layout.php` 输出二级导航 + `#dashboard-content` 容器，并在 PHP 端把 5 个子页模板（`?ajax=1` 片段）内嵌为 JSON 注入 `pageTemplates`
- 切换页面 = 注入模板 HTML + `executePageScripts` 重放脚本 + 调用子页注册的 `window.dashboardPageInit`；子页可把数据加载 Promise 挂到 `window.__pageLoadPromise` 供壳等待
- URL 通过 `history.pushState` 同步，`popstate` 回退
- 子页面图标 HTML 片段由壳以全局变量提供（`UPLOAD_ICON_SVG` 等，Phosphor `<i>` 标签字符串）

## API 代理约定

前端**不允许**持有站级 `X-API-Key`。上传相关请求一律走同源代理：

| 前端调用 | 代理目标 |
|---|---|
| `POST /api/upload` | Flask `POST /upload`（支持 SSE 流式透传） |
| `GET /api/tasks/{id}` | Flask `GET /tasks/{id}` |
| `GET /api/tasks/{id}/stream` | Flask `GET /tasks/{id}/stream`（SSE） |

Key 由 `controllers/api_controller.php` 从 `.env` 的 `UPLOAD_API_KEY` 读取注入。SSE 流式代理是长连接：PHP 内置服务器（`php -S`）单线程期间会阻塞其他请求，生产请用 Apache / Nginx + PHP-FPM。

用户级接口（`/dashboard/*`、`/api-keys/*` 等）继续直连 Flask，用 `Auth.fetch` 携带 JWT。

## 路由规范

所有路由在 `public/index.php` 中注册：

```php
$router->get('/about', 'home_controller@about');
$router->post('/api/upload', 'api_controller@upload');

// 认证保护
$router->get('/dashboard', function () {
    require_auth();
    (new dashboard_controller())->index();
});
```

## 环境变量（www/.env）

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `API_BASE_URL` | Flask 后端 API 地址 | `http://127.0.0.1:13138` |
| `UPLOAD_API_KEY` | 上传接口站级 Key（仅存服务端） | 空（未配置时代理返回 500） |
| `APP_DEBUG` | `true` 显示 PHP 错误，生产必须 `false` | `false` |

## SEO 规范

- 每页通过 `layout.php` 自动生成 title / description / OG / Twitter card / JSON-LD
- `canonical_url` 不带敏感参数（如重置令牌）
- 站内链接相对路径，外链 `rel="nofollow"`
