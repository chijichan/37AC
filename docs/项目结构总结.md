# 37AC 项目结构总结文档

## 📋 项目概述

**项目名称**: 37AC（Anime Character recognition）  
**项目类型**: 基于深度学习的二次元角色识别系统  
**架构**: 分布式C/S架构（中心服务器 + 边缘推理节点）  
**技术栈**: Python + PyTorch + Flask + TCP Socket + MySQL

## 🔄 系统工作流程

### 训练流程
1. 用户运行 `python TAC/anime_character_app.py`
2. 选择训练选项，加载数据集
3. ResNet18模型训练
4. 保存模型和类别文件到 `saves/` 目录

### 推理流程
1. 用户通过Web界面上传图片
2. Flask后端接收图片并生成任务ID
3. TCP服务分发任务到空闲边缘节点
4. 节点推理并返回结果
5. 结果存入MySQL数据库
6. Web前端轮询获取结果并展示

### 节点管理流程
1. 边缘节点启动 `node_service.py`
2. 连接中心服务器并注册
3. 发送心跳检测
4. 接收任务并进行推理
5. 返回推理结果

## ⚡ 技术特征

### 通信协议
- **传输层**: TCP长连接
- **协议类型**: 
  - JSON协议（注册、心跳、结果回传）
  - 二进制协议（任务下发、图片传输）
- **消息边界**: 长度前缀模式

### 数据流处理
1. **文本数据** → UTF-8编码的JSON
2. **二进制数据** → 原始字节流（图片等）
3. **严格区分** 避免解码错误

### 分布式特性
- **中心服务器**: Flask Web服务 + TCP服务
- **边缘节点**: 多个推理节点并行处理
- **负载均衡**: 自动选择空闲节点
- **容错机制**: 心跳检测 + 自动重连
