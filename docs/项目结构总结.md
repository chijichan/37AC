# 37AC 项目结构总结文档

## 📋 项目概述

**项目名称**: 37AC（Anime Character recognition）  
**项目类型**: 基于深度学习的二次元角色识别系统  
**架构**: 分布式C/S架构（中心服务器 + 边缘推理节点）  
**技术栈**: Python + PyTorch + Flask + PHP + TCP Socket + MySQL  
**Web界面**: Flask Web服务 + PHP MVC Web应用（双前端架构）

## 🔧 核心组件分析

### 1. CLI客户端（边缘节点）
**路径**: `src/cli/`
- **主要功能**: 模型训练、图片推理、节点服务
- **核心文件**:
  - `main.py` - 主程序入口，提供交互式菜单
  - `node_service.py` - TCP客户端，连接中心服务器
  - `predictor.py` - 图片推理功能
  - `trainer.py` - 模型训练功能

### 2. Web服务端（中心服务器）
**路径**: `src/server/`
- **主要功能**: RESTful API、任务分发、节点管理、用户认证、SSE实时推送
- **核心文件**:
  - `runserver.py` - 启动脚本（Flask + TCP双服务）
  - `services/listen_service.py` - TCP服务器，管理节点连接
  - `services/node_manager.py` - 节点注册、心跳、负载均衡
  - `services/task_dispatcher.py` - 分发任务到空闲节点
  - `services/sse_bus.py` - SSE事件总线，实时推送结果到前端
  - `services/message_handlers.py` - 消息处理（注册/心跳/结果+SSE推送）
  - `services/auth_service.py` - JWT认证、用户注册/登录/刷新
  - `routes/` - 7个Blueprint路由模块（auth、upload、dashboard、node等）

**路径**: `src/www/`
- **主要功能**: 现代化的仪表盘界面，基于Pico CSS的响应式设计
- **核心文件**:
  - `router.php` - PHP路由控制器
  - `DASHBOARD.md` - 仪表盘功能详细说明
  - `SECURITY.md` - 安全配置文档
  - `start-server.bat` - Windows启动脚本
- **架构特点**:
  - **MVC模式**: 清晰的控制器、模型、视图分离
  - **响应式设计**: 基于Pico CSS 2，支持移动端和桌面端
  - **仪表盘功能**: 统计卡片、系统监控、最近活动、数据表格
  - **组件化**: 图标组件、布局组件复用

## 🔄 系统工作流程

### 训练流程
1. 用户运行 `python TAC/anime_character_app.py`
2. 选择训练选项，加载数据集
3. ResNet18模型训练
4. 保存模型和类别文件到 `saves/` 目录

### 推理流程（当前，含SSE实时推送）
1. 用户通过PHP前端上传图片（支持裁剪/快速去背景/AI去背景）
2. 前端发送 `POST /upload` 到 Flask 后端（`Auth.fetch` 自动携带JWT令牌）
3. Flask后端接收图片、生成task_id、通过TCP分发到空闲节点
4. 前端通过 `EventSource /tasks/<task_id>/stream` 订阅实时结果
5. 节点推理完成 → TCP回传结果 → `sse_bus.publish()` → 前端即时收到
6. **降级方案**：SSE连接失败时自动回退到 `GET /tasks/<task_id>` 轮询
7. 结果展示：角色名称、置信度、概率分布条形图、萌娘百科链接

### 节点管理流程
1. 边缘节点启动 `node_service.py`
2. 连接中心服务器并注册
3. 发送心跳检测
4. 接收任务并进行推理
5. 返回推理结果

## ⚡ 技术特征

### 通信协议
- **传输层**: TCP长连接
- **协议类型**: 
  - JSON协议（注册、心跳、结果回传）
  - 二进制协议（任务下发、图片传输）
- **消息边界**: 长度前缀模式

### 数据流处理
1. **文本数据** → UTF-8编码的JSON
2. **二进制数据** → 原始字节流（图片等）
3. **严格区分** 避免解码错误

### 分布式特性
- **中心服务器**: Flask Web服务 + TCP服务
- **边缘节点**: 多个推理节点并行处理
- **负载均衡**: 自动选择空闲节点
- **容错机制**: 心跳检测 + 自动重连

## 💡 使用建议

### 开发环境配置
1. **Python环境**: 配置Python虚拟环境，安装完整依赖
2. **PHP环境**: 配置PHP 7+环境，安装Apache服务器
3. **数据库**: 安装MySQL数据库，创建相应表结构

### 部署顺序
1. **启动Flask服务端**: 运行 `python src/server/runserver.py`
2. **启动PHP Web应用**: 运行 `src/www/start-server.bat` (Windows) 或配置Apache虚拟主机
3. **启动边缘节点**: 运行 `python src/cli/main.py` 并选择节点服务

### 网络配置
1. **TCP端口**: 确保TCP端口可访问，防火墙设置正确
2. **Web端口**: Flask默认端口13138，PHP应用默认端口8000
3. **跨域配置**: 如有需要，配置CORS允许跨域请求

### 数据准备
1. **训练数据**: 按照要求准备训练数据集，每个角色至少100张图片
2. **模型文件**: 确保模型文件路径配置正确
3. **数据库**: 创建必要的数据库表结构

### 访问方式
- **Flask Web界面**: `http://localhost:13138`
- **PHP仪表盘**: `http://localhost:8000/dashboard`
- **API接口**: Flask服务提供的RESTful API

**项目状态**: ✅ 功能完整，文档基本齐全，架构稳定，支持双前端架构
